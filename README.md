# Portfolio Reditya Nur Karomah

React + Vite + Tailwind CSS v4 + Framer Motion.

## Menjalankan
```
npm install
npm run dev      # pengembangan
npm run build    # produksi (hasil di dist/)
```

## Mengubah isi
Semua teks, proyek, dan pengalaman ada di `src/data/profile.js`.

## Aset yang perlu ditambahkan ke `public/`
- `profile.png` — foto profil (sementara tampil placeholder "RN")
- `camping.png`, `mobilebanking.png` — gambar proyek (sementara tampil placeholder)
- `cv.pdf` — file CV (sudah ada). Diunduh sebagai `CV-Reditya-Nur-Karomah.pdf`.

## Tautan
Tombol GitHub/LinkedIn/proyek otomatis **disembunyikan** selama URL-nya masih
placeholder (`#` atau hanya `https://github.com/`). Isi URL asli di
`profile.js` dan tombolnya muncul sendiri.
